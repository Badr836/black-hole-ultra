# الجولة الثانية — «حَكَم» (Judge)

قرأت استخراج البلاغات (175 عنصراً)، وخطة «باني»، واعتراضات «ناقد». أحكامي ملزمة.

## أ. الأحكام على البنود السبعة

| # | البند | الحكم | الصيغة الملزمة |
|---|---|---|---|
| F1 | JS runtime | **يُعتمد** | كشف `deno > bun > node≥22`، تمرير `--js-runtimes`، تشخيص صريح، وأمر تثبيت جاهز. لا كسر عند الغياب. |
| F2 | تدوير عميل يوتيوب | **يُعتمد بشرط الناقد** | فقط بعد فشل حقيقي، عميل واحد (`android_vr` — الوحيد المُثبت عمله هنا)، يُسجّل السبب نصاً في سجل المهمة، ولا يُعاد أكثر من مرة. |
| F3 | aria2c | **يُعتمد بشرط الناقد** | `--downloader http:aria2c` (بالبادئة)، بلا `-j/-x/-s` مكرّرة، **مُعطّل افتراضياً**، ولا يُستخدم لـDASH/m3u8، ومعه تحديث تقدّم بديل (نسبة تقريبية) حتى لا تبدو المهمة معلّقة. |
| F4 | أرشيف التحميل | **يُعتمد بشرط الناقد** | «موجود في الأرشيف» = `completed` مع ملاحظة، لا `failed`. |
| F5 | SponsorBlock | **يُعتمد مُقيَّداً** | مُعطّل افتراضياً، والواجهة تقول صراحة إنه يرسل معرّف الفيديو إلى `sponsor.ink`. |
| F6 | رسالة صلاحيات الكوكيز | **يُعتمد** | نص يشرح تشفير Chrome على ويندوز وضرورة إغلاق المتصفح. |
| F7 | توسعة المزوّدات | **يُعتمد** | البنية قابلة للتوسعة؛ لا يُضاف مزوّد جديد في هذه الدورة بلا حاجة ملموسة. |

## ب. ما يُضاف إلزامياً من اعتراضات الناقد

1. **تحقق اكتمال القائمة** (Seal #736): بعد اكتمال مهمة قائمة تشغيل، إذا كان `completedEntries < المطلوب`
   تُضاف ملاحظة «قد تكون القائمة ناقصة (X من Y)» في حقل `error`/`log` مع بقاء الحالة `completed`.
2. **كشف تقادم المحرك** (83 بلاغاً): التشخيص يعرض `installed` مقابل `latest` من مراقب GitHub،
   ورسالة واحدة قابلة للتنفيذ.
3. **`--concurrent-fragments` قابل للضبط** (لا ثابت 8) بقيمة افتراضية 4.
4. **قياس فعلي**: عدّاد بسيط في التشخيص لعدد المهام بحسب المزوّد/الفشل (`providerStats`) — دليل بدل انطباع.

## د. بوابة الاعتماد للجولة الثانية

1. `typecheck` + `lint` + `test` + `build` خضراء.
2. E2E: تحليل يوتيوب **بلا تحذير runtime** عند وجود deno.
3. تحميل حقيقي عبر **aria2c** موثّق في السجل (عند تفعيله).
4. اختبارات وحدة لسياسة التدوير، وسياسة الأرشيف، وبناء وسائط SponsorBlock.
5. التشخيص يعرض: runtimes · providerStats · تقادم المحرك · حالة كل ميزة.
6. لا ميزة جديدة مفعّلة افتراضياً تخالف الخصوصية أو تخفض الجودة.
