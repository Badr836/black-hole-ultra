# الجولة الثالثة — «حَكَم» (Judge): قرارات المزوّد الثالث والاستكمال

> الطلب: تنفيذ الخطوات الثلاث المقترحة (قائمة حقيقية ≥10، مزوّد HLS ثالث، إعادة تحميل الناقص).

## أ. قرار الترخيص لمزوّد N_m3u8DL-RE — **مُعتمد**

| السؤال | الجواب المُلزِم |
|---|---|
| ترخيص الأداة | **MIT** (تحقّقت عبر GitHub API: `license.spdx_id = MIT`, 9,005 ★) |
| هل يُنسخ كودها؟ | **لا.** تُشغَّل كملف تنفيذي خارجي فقط — لا سطر مصدري واحد يدخل المستودع. |
| هل يُوزَّع الملف التنفيذي؟ | نعم، غير معدّل، مع ذكر الترخيص والمصدر في `docs/github-research.md` و`README`. |
| هل يتوافق مع ترخيص المشروع؟ | نعم — MIT متوافقة مع أي ترخيص لاحق، ولا تفرض شيئاً على بقية الكود. |
| حدوده | HLS فقط (روابط `.m3u8`). لا يُستخدم لمزوّدي الفيديو العامّين حتى لا نضاعف مسارات الأخطاء. |
| DRM | **مرفوض دائماً**: نتحقق من المانيفست قبل التنزيل (`SAMPLE-AES`/Widevine/PlayReady/FairPlay) ونوقف المهمة برسالة. لا نمرّر `--key`. |

## ب. قرارات إعادة تحميل العناصر الناقصة

1. **لا نُعيد تحميل القائمة كلها أبداً**؛ نطلب الفهارس الناقصة فقط عبر `--playlist-items` مضغوطة (`2,5-6`).
2. **حد أقصى محاولتان** (`MAX_INCOMPLETE_RETRIES = 2`) ثم رفض صريح بسبب مفهوم (محتوى محذوف/خاص).
3. **الفشل الجزئي ليس فشلاً**: قائمة يخرج فيها yt-dlp بـ`exit≠0` ومعها ملفات = `completed` + تنبيه، لا `failed`.
4. **النجاح الجزئي لا يمحو السجل**: تُدمج الملفات الجديدة مع السابقة في `files`.
5. **إعادة محاولة لا تنتج شيئاً** لا تُوصف بأن «الملف موجود مسبقاً»؛ تُوصف بأن العناصر غير موجودة/غير متاحة.

## ج. قرارات مزوّد HLS

1. يُستخدم عند اختيار المستخدم (`providerPreference=nm3u8dl`) **أو** تلقائياً عند فشل yt-dlp على رابط `.m3u8` (مرة واحدة فقط).
2. `--force-ansi-console` **إلزامي**: بدونه تنهار الأداة داخل Spectre.Console عندما يكون الخرج أنبوباً (تحقّق فعلي).
3. فشل دائم (403/404/مانيفست غير صالح) يوقف العملية فوراً بلا إعادة محاولة.
4. التقدّم يُحسب عبر المسارات (Tracks) لا نسبة المسار الحالي، وإلا قفز الشريط إلى 99.9% بعد المسار الأول.
