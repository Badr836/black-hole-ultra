# مصفوفة دعم المنصات — نسخة بعد إضافة المزوّدات

**آخر تحديث:** 2026-10-30 · yt-dlp 2026.10.26 · gallery-dl 1.32.18 · FFmpeg 7.1.5
**البيئة:** خادم محلي على عنوان مركز بيانات، بلا كوكيز.

> القاعدة التي يحكم بها التطبيق الآن: لا يوجد محرك واحد يغطي كل شيء.
> لذلك يعمل بمزوّدَين وبتوجيه تلقائي وتحويل عند الفشل، ويقول الحقيقة عند الاستحالة.

## كيف يتخذ التطبيق القرار

```
الرابط → routeProvider()
         ├── إنستغرام / X / Pinterest / ريديت / Pixiv / DeviantArt / Tumblr → gallery-dl
         ├── كل ما عدا ذلك                                                 → yt-dlp
         └── إذا فشل المحرك بخطأ «فهم الرابط» (لا يوجد فيديو / Unsupported URL / empty media)
             → تحويل تلقائي مرة واحدة إلى المحرك الآخر
```

- التوجيه قابل للتجاوز من الإعدادات: `تلقائي | yt-dlp دائماً | gallery-dl دائماً`.
- التحويل لا يحدث عند أخطاء المصادقة أو 429 (لأن المحرك الآخر سيفشل بنفس السبب).

## «الحل» لكل حالة غير مدعومة — بصدق

| الحالة | الحل المُنفَّذ فعلاً |
|---|---|
| موقع يشترط تسجيل دخول | **مدير كوكيز**: رفع `cookies.txt` من الإعدادات، مع تحليل يقول أي المنصات مغطاة وأي جلسة موجودة (`/api/cookies`) |
| منشور صور لا فيديو | **gallery-dl** كمزوّد ثانٍ + نوع وسائط `image` في قاعدة البيانات والواجهة |
| محرك لا يفهم الرابط | **تحويل تلقائي** إلى المحرك الآخر مرة واحدة (مُختبر) |
| الموقع يحظر بالـ429 | **كشف فوري**: كانت المهمة تنتظر دقائق (المحرك ينام دقيقة بين المحاولات). الآن تفشل في **2 ثانية** برسالة تشرح السبب |
| مهمة تعلق بلا أي مخرجات | **Watchdog**: إيقاف بعد 5 دقائق صمت (قابل للضبط بـ`BLACKHOLE_IDLE_TIMEOUT_MS`) مع سبب واضح |
| موقع جديد لا يعرفه المحركان | **مراقب GitHub**: يفحص إصدارات yt-dlp/gallery-dl والمشاريع المرشحة (lux، instaloader، N_m3u8DL-RE) ويقترح التحديث |
| DRM | **لا حل مشروع** — البديل الرسمي: التنزيل داخل التطبيق (Netflix/Spotify offline) أو شراء المحتوى |

## أوامر

```bash
pip install -U "yt-dlp[default,curl-cffi]" gallery-dl   # yt-dlp للفيديو + gallery-dl للمنشورات
npm run upstream:check                                  # ماذا تغيّر في GitHub؟
npm run upstream:update                                 # تحديث المحركات
```

## حدود لا تُخفى

1. الكوكيز = جلستك الشخصية. لا تُرسل لأي خدمة، لكنها تمنح التطبيق صلاحيات حسابك: استخدم حساباً ثانوياً إن أردت.
2. عناوين مراكز البيانات تُحظر أكثر من الشبكة المنزلية (إنستغرام 429 مثال حي).
3. المواقع تتغيّر؛ تحديث المحركات هو الصيانة الحقيقية، لا تعديل الكود.

| نطاقه | روابط `.m3u8` فقط — لا يحلّ محل yt-dlp للفيديو العام |
