## ٦) القيود الصادقة — اقرأها

1. **هذه ليست استضافة دائمة ٢٤/٧.** GitHub Codespaces حصتها المجانية ≈ ١٢٠ ساعة‑نواة شهرياً = **~٦٠ ساعة تشغيل** على نواتين. إذا استُهلكت، يتوقف التشغيل حتى بداية الشهر التالي (أو ترقية الحساب).
2. **خمول ٤ ساعات:** الـ Codespace يتوقف تلقائياً بعد ٤ ساعات بلا استخدام؛ الحراسة تعيده عند أول فحص (خلال ≤٣٠ دقيقة)، وأول فتح بعد التوقف قد يأخذ ~٣٠ ثانية.
3. **البيانات:** قاعدة SQLite موجودة داخل جهاز التشغيل. محفوظة بين مرات التوقف/التشغيل، لكنها تُفقد إذا حُذف الـ Codespace (يحذفه GitHub تلقائياً بعد ٧ أيام متصلة وهو متوقف).
4. **الرابط قبيح وطويل** لأنه اسم مولَّد من GitHub — يمكن اختصاره لاحقاً.
5. **الأمان:** التوكن الذي أرسلته محفوظ الآن كسرّ في المستودع باسم `CODESPACE_PAT` (لأن الحراسة تحتاجه). أنصح بإبطاله وتوليد غيره بعد أن نستقر على استضافة دائمة.
