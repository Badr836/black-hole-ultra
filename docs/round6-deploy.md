## 2) كيف تم النشر (وما الذي يعمل الآن)

1. `npm run build` — نسخة إنتاج محسّنة (`next start`، لا وضع تطوير).
2. الخادم يعمل على المنفذ 3000 داخل الجهاز/الحاوية (`HOSTNAME=0.0.0.0`).
3. نفق HTTPS عام عبر Cloudflare Quick Tunnel (بدون حساب) — يعطي نطاقاً حقيقياً بشهادة TLS صالحة.
   **HTTPS ليس ترفاً**: المتصفحات لا تسمح بتثبيت PWA ولا بتشغيل Service Worker على HTTP (عدا `localhost`).
4. الرابط المختصر على `spoo.me` مع اسم ثابت `bh-ultra`، ورمز QR مولّد منه.
5. أداة تكرار: `./scripts/share.sh` تقوم بكل ما سبق بأمر واحد (بناء → تشغيل → نفق → اختصار → QR)، وتعيد استخدام نفق حيّ بدل فتح نفق جديد، وإن كان الاسم محجوزاً تنشئ اسماً بديلاً وتتحقّق من أن الاختصار يوجّه فعلاً إلى النفق الحالي.

```
bash scripts/share.sh            # كل شيء من الصفر
bash scripts/share.sh --no-build # إعادة استخدام بناء موجود
```

## 3) ما تم التحقّق منه فعلياً (ليس تقديراً)

كل الفحوص شُغّلت على **الرابط العام عبر HTTPS** بمحرّكات Playwright الحقيقية الثلاثة، لا على محاكاة أسماء متصفحات:

| المحرّك | يمثّل | النتيجة |
|---|---|---|
| Chromium | Chrome / Edge / Opera / Brave / Vivaldi / Samsung Internet | **18/18 ✓** |
| Firefox | Firefox (Gecko) — سطح المكتب وأندرويد | **17/17 ✓** |
| WebKit | Safari على macOS و iOS/iPadOS وكل متصفحات iOS | **17/17 ✓** |

الفحوص المشتركة لكل محرّك (52 فحصاً إجمالاً):

- الصفحة تُحمّل وتُعرض، والعنوان صحيح، والمستند `dir="rtl"` بالعربية.
- `link rel=manifest` موجود، و`/manifest.webmanifest` يُخدَم بـ `application/manifest+json`، ويحتوي `name`/`short_name`/`start_url`/`display: standalone`، وأيقونات 192 و512 وmaskable.
- **كل** أيقونة في البيان تُحمَّل فعلياً 200 وبـ `image/png` (أيقونة مفقودة = تثبيت مكسور بصمت).
- Service Worker: مدعوم، يصل إلى `activated`، ويصبح المتحكّم في الصفحة.
- واجهة: لوحة HLS تفتح، لوحة الإعدادات تفتح، قسم «أمان الوصول» يُعرض.
- الجوال (390×844): صفر تجاوز أفقي، حقول الإدخال ≥16px (منع تكبير iOS التلقائي)، صفر أخطاء وقت التشغيل.
- **صفر أخطاء console** في كل محرّك.
- في Chromium فقط: `Page.getInstallabilityErrors` من DevTools = **قائمة فارغة** — أي أن المتصفح نفسه يعتبر التطبيق قابلاً للتثبيت.

مصفوفة الأجهزة (لمس + كثافة بكسل + وكيل مستخدم حقيقي):

## 5) التثبيت كتطبيق — خطوة بخطوة

### أندرويد (Chrome / Edge / Samsung Internet / Brave)
1. افتح https://spoo.me/bh-ultra.
2. سيظهر زر **«⬇ تثبيت التطبيق»** أعلى الصفحة — اضغطه واختر «تثبيت».
   أو من قائمة المتصفح (⋮) ← **«تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية»**.
3. تصبح الأيقونة على الشاشة الرئيسية، وتفتح بملء الشاشة (بلا شريط عنوان).

### iPhone / iPad (Safari — إلزامي)
1. افتح الرابط في **Safari** (ليس Chrome على iOS).
2. زر **المشاركة** ⤴ في الشريط السفلي.
3. **«إضافة إلى الشاشة الرئيسية»** ← «إضافة».
4. يعمل التطبيق بملء الشاشة مع احترام الحواف الآمنة (notch).

### Windows / macOS / Linux / ChromeOS (Chrome أو Edge)
1. افتح الرابط، ثم أيقونة **التثبيت** في شريط العنوان، أو ⋮ ← «تثبيت BlackHole Ultra…».
2. تُنشأ نافذة تطبيق مستقلة + اختصار في قائمة Start / Launchpad.

### ما الذي يعمل بعد التثبيت
- فتح بملء الشاشة بهوية التطبيق، أيقونات نظامية، و`theme-color` داكن مطابق للواجهة.
- اختصارات سريعة (long-press أو right-click على الأيقونة): «تحميل جديد» و«قائمة التحميلات».
- **صمود الشبكة**: الـService Worker يخزّن هيكل الواجهة؛ إن انقطع الاتصال تُعرض صفحة «بلا اتصال» عربية بدل خطأ المتصفح. طلبات `/api/*` لا تُخزَّن أبداً — لا بيانات قديمة مضلِّلة.
- تحديث ذاتي: عند نشر نسخة جديدة يكتشفها الـSW ويتفعّل فوراً.

## 6‑أ) لماذا تتوقّف الروابط؟ (وما فعلته لمنع ذلك)

**السبب الحقيقي (لا علاقة له بالتطبيق):** البيئة السحابية التي يعمل فيها الخادم تقطع أنفاق «بلا حساب»:

| ما حدث | الدليل |
|---|---|
| Cloudflare ألغى تسجيل النطاق من جهته | `curl` يعيد `000` / المتصفح يعرض **Error 1033**، بينما الخادم المحلي `200` |
| localhost.run يخنق الأصول الكبيرة أحياناً | `/icons/icon-512.png` استغرق **40 ثانية** مرة، و`0.19s` في مرة أخرى |
| الحاوية تنام عند الخمول | كل العمليات (الخادم + النفق) تتوقف معها |

**الحل الهندسي المطبَّق — `scripts/keep-online.sh` (يعمل الآن):**

1. **ثلاثة مزوّدين بالتناوب**: `localhost.run` ← `cloudflare` ← `pinggy`.
2. **فحص قبول صارم** قبل نشر أي رابط: `/api/health` + `/manifest.webmanifest` + **تنزيل أيقونة 512 كاملة (>30KB)** — لأن أيقونة ناقصة تعني فشل تثبيت PWA بصمت.
3. **3 إخفاقات متتالية ⇒ تبديل المزوّد** ونشر رابط مختصر جديد + QR + بطاقة تلقائياً.
4. **`docs/live.json` / `docs/live.md`** هما المصدر الوحيد للحقيقة: الرابط الحيّ الآن + المزوّد + وقت التحديث.

**ملاحظة أمان:** أضفت نطاقات الأنفاق (`lhr.life`, `loca.lt`, `pinggy.link`, `serveo.net`, `tunnelmole.net`, `ngrok.io`) إلى قائمة `PREVIEW_HOST_PATTERNS` في `src/lib/access.ts` حتى لا يظهر «رمز الوصول مطلوب» على نطاق النفق — مع اختبارات وحدة للنطاقات الجديدة (152/152).

**ولرابط دائم فعلاً** (لأن أي نفق بلا حساب مؤقّت بطبيعته) — **المسار المختار: Tailscale**:
- **Tailscale Serve**: شهادة HTTPS صالحة بلا نطاق ⇒ يعمل التثبيت من الجوال في أي مكان، والرابط لا يتغيّر.
  الدليل الكامل: **`docs/tailscale.md`** · الأتمتة: **`scripts/tailscale-join.sh`** (`TSAUTHKEY=tskey-auth-… bash scripts/tailscale-join.sh`).
  أُضيف النطاق `*.ts.net` إلى قائمة السماح في `src/lib/access.ts` (مع اختبار وحدة) كي لا يظهر «رمز الوصول مطلوب».
- **نفق Cloudflare مسمّى + نطاقك**: الخطوات في القسم أدناه.
- أو تشغيل التطبيق على جهازك مباشرة (`npm start`) — وهو الاستخدام الصحيح لمدير تحميل.



**ما حدث:** النفق الأول (`chronicle-…`) بقي تشغيلياً لكن Cloudflare ألغت تسجيل النطاق من جهتها، فصار `curl` يعيد `000` (النطاق لا يُحلّ أصلاً) بينما الخادم المحلي سليم `200`. النتيجة: الرابط المختصر يوجّه إلى نطاق ميت ⇒ «الروابط لا تشتغل».
نفق `trycloudflare` بلا حساب **لا يضمن بقاء النطاق**؛ هذا قيد الخدمة نفسها لا خطأ في التطبيق.

**ما أُضيف لمنع تكراره:**

| الأداة | الدور |
|---|---|
| `scripts/tunnel-watch.sh` | **حارس يعمل الآن**: كل 45 ثانية يفحص `/api/health` عبر الرابط العام؛ إن سقط مرّتين يعيد تشغيل النفق، ينشئ **رابطاً مختصراً جديداً**، ويعيد توليد QR + بطاقة التثبيت + `docs/live.json` تلقائياً. يعيد تشغيل خادم Next إن سقط أيضاً. |
| `docs/live.json` / `docs/live.md` | المصدر الوحيد للحقيقة: الرابط الحي الآن + وقت آخر تحديث. |
| `scripts/live-card.py` | يعيد توليد QR والبطاقة من `live.json` بأمر واحد. |
| `scripts/share.sh` | النشر الأولي بأمر واحد (بناء → خادم → نفق → اختصار → QR). |

**لرابط دائم لا يتغيّر** (الخيار الصحيح للإنتاج): نفق مسمّى بحساب Cloudflare مجاني + نطاقك الخاص:

```bash
cloudflared tunnel login
cloudflared tunnel create blackhole
cloudflared tunnel route dns blackhole app.example.com
cloudflared tunnel run --url http://127.0.0.1:3000 blackhole
```

أو أي VPS مع `docker compose` ونطاق + Caddy/Nginx لشهادة TLS (يمكن تثبيت PWA بعدها كالمعتاد).

## 6) حدود يجب أن تعرفها (بصراحة)

1. **النفق مؤقّت**: Cloudflare Quick Tunnel بلا حساب ليس له ضمان استمرارية؛ إذا توقّف السكربت/الحاوية يتوقف الرابط العام، وعند إعادة التشغيل يتغيّر النطاق (يصبح الاختصار `bh-ultra` قديماً ويحتاج تحديثاً — `scripts/share.sh` يعالج ذلك ويعيد إنشاء اختصار صالح مع تحذير). أثناء العمل لاحظت انقطاع QUIC لمرة أثناء إعادة تشغيل الخادم وأعاد النفق الاتصال تلقائياً (بضع ثوانٍ من 530). للحصول على نطاق ثابت: نفق مسمّى بحساب Cloudflare أو VPS/نطاق خاص.
2. **الرابط العام يعرض تطبيقاً يعمل على هذه الآلة**: التحميلات تُنفَّذ بـ yt‑dlp/FFmpeg على جهاز الخادم نفسه، وتُخزَّن ملفاته هناك. مشاركة الرابط = مشاركة جهازك. لحمايته: رمز الوصول (⚙️ الإعدادات ← أمان الوصول) و/أو أوقف النفق بعد الاستخدام.
3. **الروابط المختصرة عبر خدمة عامة** (spoo.me): أي شخص يملك الرابط يصل إلى التطبيق — لا تعتبرها سرّاً.
4. **iOS**: التنبيهات (Web Push) لا تعمل على iPhone/iPad؛ التنبيه المحلي داخل التطبيق يعمل. على أندرويد/سطح المكتب يعمل زر 🔔 بعد منح الإذن.
5. **بعض المتصفحات القديمة** (iOS < 16.4، Safari < 14، Firefox < 100) لا تدعم كل ميزات PWA — التطبيق يعمل لكن لا يُثبَّت.
6. **معاينة المنصّة** (`https://3000-…e2b.app`) محميّة برمز مرور لا يمكن للخدمات تمريره، لذا التحقّق الآلي تم على `127.0.0.1:3000` للنسخة المحلية وعلى رابط النفق للنسخة العامة.
