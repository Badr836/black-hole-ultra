# نشر دائم بنقرة واحدة (Tailscale) — بدون نطاق وبدون نفق يتوقف

> لماذا؟ الأنفاق المجانية (trycloudflare / localhost.run) تنقطع بعد دقائق داخل بيئات
> التشغيل السحابية، فتظهر أخطاء مثل **Cloudflare 1033**. Tailscale يعطيك
> **رابط HTTPS ثابتاً بشهادة صالحة** يعمل من الجوال في أي مكان، ويقبل تثبيت التطبيق (PWA).

> **ملاحظة صريحة:** لا يمكن تشغيل Tailscale داخل الحاوية التي أعمل فيها — تحققتُ أن
> `controlplane.tailscale.com` و`login.tailscale.com` **محجوبان من الشبكة** (حتى بالاتصال بالـIP المباشر).
> كما أن الحساب يجب أن يكون حسابك أنت. لذلك جهّزتُ لك الحلّ ليعمل على جهازك: نقرة واحدة.

---

## Windows — انقر مرتين

1. نزّل المشروع على جهازك (ZIP أو `git clone`).
2. انقر مرتين على **`START-WINDOWS.bat`**.
3. سيفعل تلقائياً:
   - تثبيت **Node.js / yt-dlp / FFmpeg / Tailscale** الناقص (عبر winget).
   - `npm ci` ثم `npm run build`.
   - تشغيل الخادم على `http://127.0.0.1:3000`.
   - `tailscale up` (يفتح المتصفح **مرة واحدة** لتسجيل الدخول بحسابك المجاني).
   - `tailscale serve --bg 3000` ثم يطبع رابطك ويفتحه:
     `https://<اسم-جهازك>.<شبكتك>.ts.net`

**إن ظهرت رسالة عن الشهادة:** افتح <https://login.tailscale.com/admin/dns> ←
فعّل **HTTPS Certificates** و**MagicDNS**، ثم أعد تشغيل الملف.

## macOS / Linux

```bash
bash scripts/serve-tailscale.sh          # تجهيز + تشغيل + نشر
bash scripts/serve-tailscale.sh --serve  # النشر فقط إن كان الخادم يعمل
```

## من الجوال (أندرويد أو iPhone)

1. ثبّت تطبيق **Tailscale** من المتجر وسجّل الدخول **بنفس الحساب**.
2. تأكد أن الـVPN مفعّل.
3. افتح الرابط `https://…ts.net`.
4. ثبّت التطبيق:
   - **أندرويد (Chrome/Edge):** زر «⬇ تثبيت التطبيق».
   - **iPhone (Safari):** مشاركة ⤴ ← «إضافة إلى الشاشة الرئيسية».

بعد التثبيت: يفتح بملء الشاشة، اختصارات سريعة، وصفحة «بلا اتصال» عربية.
التنزيلات تُنفَّذ على حاسوبك، والجوال يتحكّم بها — وهو الاستخدام الصحيح لمدير تحميل.

## ما أضفته في المشروع لهذا الغرض

| الملف | الدور |
|---|---|
| `START-WINDOWS.bat` | نقطة التشغيل على Windows (نقرة مزدوجة) |
| `scripts/windows-start.ps1` | التجهيز الكامل + البناء + Tailscale Serve + طباعة الرابط |
| `scripts/serve-tailscale.sh` | نفس الشيء لـ macOS/Linux |
| `scripts/tailscale-join.sh` | لحاوية/سيرفر بعيد تملكه: انضمام بمفتاح `TSAUTHKEY` + نشر |
| `src/lib/access.ts` | إضافة `*.ts.net` إلى نطاقات السماح (لا يظهر «رمز الوصول مطلوب») + اختبار وحدة |

## حلّ المشكلات

| العرض | الحل |
|---|---|
| `502` على رابط ts.net | الخادم متوقف: شغّل `npm start` (أو أعد `START-WINDOWS.bat`) |
| `serve: access denied` أو خطأ شهادة | فعّل **HTTPS Certificates** من لوحة Tailscale |
| الجوال لا يفتح | تطبيق Tailscale غير مفعّل على الجوال، أو حساب مختلف |
| الملفات تُنزَّل في مكان غير متوقع | ⚙️ الإعدادات ← مجلد الإخراج |
| أريد الوصول دون تطبيق Tailscale | استخدم `tailscale funnel` (يجعلها عامة) — وفعّل رمز الوصول أولاً من ⚙️ الإعدادات |
